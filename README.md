# VideoLov

**Автор и правообладатель собственного кода: M0904sha.**

Программа для **Windows 10/11 x64**: анализ ссылок на видео и карточки товара, превью, выбор реально доступного качества, загрузка, очередь и сохранение аудио.

**[Скачать установщик](https://github.com/yasinsckijtema1907-eng/VideoLov/releases/latest)** · **[Поддержать проект](https://finance.ozon.ru/apps/sbp/ozonbankpay/01a15626-f41a-7445-915d-3349d0f96806)**

## Установка и работа

1. Скачайте `VideoLov-Setup-1.2.2.exe` в Releases и установите программу. Права администратора и отдельная установка Python, Node.js или FFmpeg не нужны.
2. Откройте «VideoLov» с рабочего стола и вставьте адрес ролика или карточки товара. Анализ начнётся автоматически; его также можно запустить кнопкой «Найти видео». Выберите найденный ролик, посмотрите превью, выберите доступное качество и нажмите «Скачать выбранное видео».
3. Если ссылка не распознана, перейдите в «Найти на странице», откройте сайт и запустите видео. Вернитесь в окно программы: найденные MP4, HLS и DASH появятся в списке.
4. Выберите поток и нажмите «Скачать». Если сайт требует входа, войдите во встроенном браузере и включите «Использовать вход…» на странице загрузки. Этот вход применяется и к анализу, и к скачиванию; профили Chrome не читаются.

В списке качества отображаются варианты конкретного видео, например 720p, 540p и 360p. Недоступные 1080p или 4K не предлагаются. Если сайт не сообщает разрешение и его не удаётся прочитать, вариант обозначается «Исходное качество». Видео не увеличивается искусственно. Для прямых MP4/WebM доступно воспроизведение превью. Для HLS/DASH или несовместимого потока программа готовит совместимый отрывок первых 6 секунд. Само скачивание сохраняет полный исходник. Если сайт закрывает и поток превью, остаётся кадр с понятным пояснением.

В карточках Alibaba читаются mediaItems; в Ozon — JSON галереи data-state и widgetStates; в AliExpress — runParams/videoModule и другие опубликованные JSON-данные; в Wildberries — опубликованные ссылки, HLS и MP4 действующего CDN. Сервер выбирается по идентификатору товара, разрешение читается из самого видео. Потоки разной длительности показываются как отдельные ролики. Динамические карточки дополнительно открываются в изолированном скрытом окне Chromium, без нажатия воспроизведения. Рекомендательные блоки исключаются из разбора JSON. Поддерживаются также JSON-LD VideoObject, HTML video/source и опубликованные MP4/HLS/DASH.

**Совместимость не является гарантией для любой карточки.** На реальных карточках Ozon 3025956623 и Wildberries 162246509 проверены поиск по ссылке, превью и сохранение готовых файлов. Wildberries отдаёт короткий MP4 360×480 и отдельный HLS-ролик 810×1080: они не смешиваются в одном выборе качества. При повторной проверке Ozon запросил проверку посетителя. AliExpress.ru показал CAPTCHA, а после ручной попытки — сообщение о необычном трафике сети; успешное скачивание с реальной карточки AliExpress пока не подтверждено. Проверку посетителя нужно пройти самостоятельно во встроенном браузере и повторить анализ. CAPTCHA автоматически не решается.

VK / VK Видео, YouTube (включая короткие ссылки), Instagram / Reels обрабатываются установленным yt-dlp. Публичные проверочные ролики всех трёх сайтов скачаны и проверены FFprobe. Закрытые аккаунты, региональные ограничения, удалённые публикации, DRM и требования входа могут сделать конкретную ссылку недоступной.

**Водяные знаки:** приложение не добавляет свои знаки, не накладывает логотип и не перекодирует скачиваемое видео ради их удаления. При наличии явно обозначенного варианта без знака он предпочтительнее в том же разрешении. Уже вписанный в изображение логотип остаётся частью исходного видео. Обещания скачать абсолютно любой сайт без любого водяного знака нет.

По умолчанию файлы сохраняются в системную папку «Видео» → «VideoLov». Папку можно изменить. Исходные файлы не перезаписываются. В истории доступны отмена, повтор и показ готового файла.

## Возможности и ограничения

- yt-dlp для поддерживаемых им сайтов, прямых файлов, HLS / DASH.
- Превью и доступные разрешения каждого найденного ролика, выбор точного варианта, извлечение MP3.
- Несколько видео в карточке товара можно выбирать независимо.
- Очередь до 30 задач, прогресс, скорость, отмена, повтор, локальная история.
- Встроенный Chromium с обнаружением потоков по адресам и MIME-типам.
- Изолированный временный браузерный сеанс. Профили, пароли и cookies Chrome не читаются.
- Нет телеметрии и загрузки видео на сторонний сервер. История ссылок хранится локально в `%APPDATA%/videolov/state.json`; «Очистить историю» удаляет записи, сохраняя сами видео.

Поддержка зависит от сайта. DRM, платный доступ и ограничения учётной записи не обходятся. Некоторые сайты блокируют встроенные браузеры. `blob:` не является самостоятельным скачиваемым файлом: программа ищет лежащие под ним сетевые потоки. Прямой поток может требовать referer, вход или иметь истекающую ссылку. Для YouTube результат зависит от доступности сайта и текущей поддержки yt-dlp; обход блокировок сети не встроен.

Скачивайте материалы, на которые имеете права или разрешение. Video Hunter послужил ориентиром по функциям; его код и оформление не копировались.

## Сборка из исходников

Нужны Windows x64, Node.js 24+ и доступ в интернет:

```powershell
npm ci
npm run tools
npm test
node scripts/smoke.js
npm run dist
```

`npm run tools` загружает официальные yt-dlp, FFmpeg и Node.js; версии и SHA-256 сохраняются в `tools/versions.json`. Установщик находится в `dist/`. Перед выпуском обновлённых инструментов повторите проверку. Автоматического скачивания и выполнения обновлений в установленной программе нет.

Тест `scripts/smoke.js` создаёт собственные ролики, HLS и карточку с двумя видео; проверяет превью, точный выбор 360p, реальные скачивания MP4/HLS/MP3 в кириллическую папку, сохранность файлов, отмену, повтор и изоляцию браузера. Результаты: `test-results/report.json`. Для проверки установленной сборки задайте `VIDEOLOV_EXECUTABLE` — путь к её `VideoLov.exe`.

### Исправления 1.2.1

Исправлены сервер Wildberries, поиск MP4 и передача адреса карточки при получении превью. Разрешение Wildberries проверяется по самому файлу, разные ролики разделяются по длительности. Исправлено отображение времени около границы минуты. Добавлены проверки реальных карточек Ozon и Wildberries, тест передачи Referer через Chromium и резервное превью обычного HLS через ограниченную загрузку первого сегмента, когда прямой запрос FFmpeg не проходит.

### Обновление 1.2.0

Разбор карточек Ozon/Wildberries/AliExpress, раскрытие HLS/DASH в реальные варианты, совместимое превью, вход во встроенном браузере для анализа и скачивания, понятные сообщения о недоступности. Проверяются 18 модульных сценариев и реальные файлы из приложения. Автор и кнопка поддержки сохранены.

### Исправление в 1.1.0

В Windows устранена ошибка чтения кириллицы в имени или пути итогового файла: yt-dlp принудительно использует UTF-8, вывод читается без разрыва многобайтных символов, имена файлов передаются в JSON. Ранее скачанное видео, ошибочно отмеченное как отсутствующее, восстанавливается в истории после проверки FFprobe. Перед обновлением истории сохраняется резервная копия `state-before-1.1.0.json`.
